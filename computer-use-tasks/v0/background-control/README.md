# Background control contract

The fixture export must exactly report the requested text, button, and menu
state. Independently, the native runner must provide a read-only hash-chained
ledger sourced from `NSWorkspace` foreground observations and
`computer-use-mcp` delivery metadata. Every sampled action must leave a
separate guard app foreground, keep the target inactive, and use app-targeted
AX or per-window delivery. Target activation or any global delivery tier fails
the task.

The OpenBench native runner binds the target and guard to separate processes
and samples the guard throughout the agent phase. This task remains native
macOS-only and does not claim Harbor execution compatibility.
