# Background control contract

The fixture export must exactly report the requested text, button, and menu
state. Independently, the native runner must provide a read-only hash-chained
ledger sourced from `NSWorkspace` foreground observations and
`computer-use-mcp` delivery metadata. Every sampled action must leave a
separate guard app foreground, keep the target inactive, and use app-scoped AX
delivery. Target activation or any global delivery tier fails the task.

The current experimental OpenBench native runner requires its target app to be
foreground and therefore does not yet satisfy this sidecar. This package does
not weaken that runner or claim Harbor compatibility.
