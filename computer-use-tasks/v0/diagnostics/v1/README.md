# Controlled diagnostic negatives

These fixtures pin expected classifications for known computer-use failure
modes. They support analysis of a trial but are not pass criteria for
`basic-controls`, `background-control`, or `textedit-exact-file`.

Each file uses `openbench.computer-use.diagnostic.v1` and describes a
controlled stimulus, independently observed effect, and expected deterministic
classification. No model or screenshot judges these outcomes.
